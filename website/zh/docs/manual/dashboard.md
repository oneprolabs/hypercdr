# 仪表盘

登录后默认进入的页面。它用于快速定位异常，不替代任务列表和日志。

![平台概览中的保护活动、任务趋势与集群状态](/images/overview/dashboard-149.png)

截图为 149 环境，数字和集群名只是示例。看的时候先确认左上角的集群选择器和时间范围，再读具体指标。

## 两种视图

仪表盘区分**平台概览**和**所选集群概览**：

| 视图 | 范围 | 用途 |
| --- | --- | --- |
| 平台概览 | 本组织下的全部集群与任务 | 整体保护覆盖、近期失败趋势 |
| 集群概览 | 当前选中的单个集群 | 该集群的资源、任务和保护状态 |

集群选择器和时间范围共同决定图表内容。**不能把所有指标都理解为平台总量**：切换集群后，数字会随之变化。

## 指标解读

- **先看趋势，再看绝对值。** 单点数值受集群规模影响，趋势能反映保护和恢复是否稳定。
- **失败记录的信息量更大。** 成功任务数量增长可能只是调度变密，失败通常指向存储、权限或网络的具体问题。
- **空数据不能算健康。** 没有任务可能是策略未生效，也可能是任务在报错。
- **不要用示例数据解释结果。** 页面上的数字以真实任务记录为准。

## 仪表盘的证据边界

::: warning 仪表盘只是汇总视图

仪表盘是汇总视图，不能替代具体页面的检查结果。以下判断需要回到对应页面：

- 存储是否可写：查看[任务详情](/docs/manual/tasks)。
- 恢复是否可用：执行[演练](/docs/manual/drill)。
- 集群是否健康：查看集群状态和 Agent 日志。`/healthz` 成功不代表注册组件可用。

:::

## 常见异常信号

| 现象 | 可能原因 | 下一步 |
| --- | --- | --- |
| 集群显示 offline | Agent 未运行、WSS 不可达、证书问题、注册凭据失效 | [故障排查](/docs/operations/troubleshooting) |
| 任务持续失败 | 对象存储权限、PVC/StorageClass、资源映射 | 查看任务详情中的错误与日志 |
| 有策略但没有任务 | 策略未绑定应用、调度未到期、保护配置未启用 | 检查[应用容灾保护](/docs/manual/application-dr) |
| 恢复点数量不增长 | 备份失败，或保留规则正在清理 | 对照[保护策略](/docs/manual/policies)的保留规则 |
