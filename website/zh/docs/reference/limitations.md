# 限制与安全建议

本页分两部分：**能力边界**（无法实现或不应依赖的行为）和**安全默认值**（部署后必须调整的不安全配置）。

## 能力边界

### 版本与升级

| 限制 | 说明 |
| --- | --- |
| 平台升级不包含组件升级 | 集群内 Agent/Velero/OADP 需要独立升级任务和验收 |
| 迁移不可逆 | 已应用的 SQL 迁移不会因流量回滚而撤销 |
| 回滚不恢复数据 | `--rollback` 只切回应用版本，不还原数据库 |
| 单一持久化实现 | PostgreSQL 是唯一实现，没有内存回退 |

### 备份与恢复

| 限制 | 说明 |
| --- | --- |
| 存储可用性取决于集群侧 | 平台无法绕过 CSI 插件、网络策略和凭据问题 |
| 任务成功 ≠ 恢复可用 | 必须通过演练验证 |
| 部分恢复可能显示为成功 | 少数资源失败时任务状态可能仍然正常，需逐项核对 |
| 恢复会覆盖目标 | 执行前必须核对资源映射 |
| 恢复缓存不会自动回退 | 运行时创建缓存 PVC 失败不会退回临时盘，由预检环节拦截 |

### 集群类型专项

CCE 与 OpenShift 各有第一阶段范围，超出范围的能力不提供支持：

- CCE：不支持 Autopilot、Windows 节点、ARM64 节点、exec-plugin kubeconfig；见 [CCE 专项](/docs/reference/cce)。
- OpenShift：仅全量备份、RWO PVC、S3 存储、OADP `stable-1.3` 通道；见 [OpenShift 专项](/docs/reference/openshift)。

## 安全建议

### 部署后立即处理

::: danger 三项必须修改的配置

1. **修改初始密码。** 首次登录账号为 `admin`，密码为 `admin123`，业务使用前必须修改。
2. **更换自签证书。** 安装器自动生成的证书不被浏览器信任，正式环境应使用自有 CA 签发的证书。
3. **保护 `HCDR_SECRET_KEY`。** 它是平台秘密数据的保护密钥，丢失后只恢复数据库也无法解密。

:::

### 凭据管理

- `.env`、kubeconfig、私钥、证书、数据库备份**都不能提交到仓库**。
- 分享日志和错误信息前，去掉 token、密码、kubeconfig 和私钥。
- Google Client Secret 不得写入前端，也不得提交到仓库。
- 对象存储凭据使用最小权限的专用账号，不复用在其他系统。
- 注册命令包含访问凭据，在 issue 中粘贴前必须脱敏。

### 网络

- 只有 12443 暴露到宿主机，数据库、API、前端和注册执行器不直接发布端口。
- 使用外部代理时，代理的生命周期和证书由部署者管理，平台升级不会修改。
- Agent 使用**出站**连接，平台不需要主动访问集群。

### 数据保护

- 数据库运行期间直接复制 PostgreSQL 数据目录，无法得到一致性备份。
- 升级前备份：PostgreSQL、`.env`、TLS、Compose 配置、版本清单。
- 应用备份数据存放在对象存储中，生命周期独立于平台数据库，需要分别制定保留策略。
- `--purge-data` 会删除安装目录且不可恢复，执行前确认清理范围。

### 常见操作误区

::: warning 错误码与命令的区别

`component_target_unavailable` 这类内容是错误码，不能作为 shell 脚本粘贴执行。遇到不熟悉的错误提示时，先确认它属于哪类信息，再决定处理方式。

:::
