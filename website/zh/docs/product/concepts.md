# 核心概念

平台的页面按组织、集群、存储、策略、应用容灾、任务、恢复点的顺序组织：组织是资源边界，集群和存储归属于组织，策略在集群上配置，策略产出任务和恢复点，恢复点用于演练和接管。

## 概念一览

| 概念 | 含义 | 界面位置 |
| --- | --- | --- |
| 组织 | 资源隔离边界。一个账号只属于一个组织 | Settings → Organization |
| 集群 | 已注册的 Kubernetes / CCE / OpenShift 集群 | Configuration → Clusters |
| 存储 | 对象存储地址、bucket 与凭据 | Configuration → Storage |
| 策略 | 保护策略的调度与保留规则 | Configuration → Policies |
| 应用容灾 | 源 Namespace、目标端与存储的组合保护配置 | DR → Application DR |
| 任务 | 一次备份或恢复的执行记录 | Backup & Recovery Tasks |
| 恢复点 | 某次成功备份产出的可恢复时间点 | Restore Points |
| 演练 | 在隔离范围验证恢复是否可用 | Drill |
| 恢复 | 恢复任务的能力与任务记录类型；可用入口是 Drill 和 Takeover | Backup & Recovery Tasks |
| 接管 | 按容灾切换流程把业务切到目标端，需先通过校验和变更审批 | Takeover |
| 同步 / 备份 | 一次数据同步或备份执行，由 Agent 完成并产出恢复点 | Tasks |

## 关系模型

```text
组织
├── 集群（源 / 目标，按集群类型区分安装路径）
├── 存储（对象存储，可被多个策略引用）
├── 策略（计划 + 保留规则）
└── 应用容灾
    ├── 源 Namespace 范围
    ├── 目标集群
    ├── 存储
    └── 策略
        └── 任务 → 恢复点 → 演练 / 恢复
```

## 易混淆的概念

**源集群与目标集群相互独立。** 保护流程同时需要源集群和目标集群。某个集群能否作为恢复目标，取决于具体应用和恢复配置，不能默认成立。

**保存成功只说明配置已写入。** 存储配置只是一条引用，实际访问权限和数据路径需要通过一次备份和恢复验证。

**Namespace 范围与应用边界需要分别确定。** 一个应用可能跨多个 Namespace，多个应用也可能共用一个 Namespace。选择恢复范围时按业务需要判断，并提前确定独立还是合并。

**任务成功只说明执行流程结束。** 恢复是否可用，取决于演练结果和应用校验。

**平台管理员没有跨组织业务权限。** 平台管理员的权限只覆盖用户、组织等平台管理，不包含跨组织的业务资源。业务页面不提供组织切换。

## 恢复点与恢复的边界

- **保护配置**把源集群、应用/Namespace、策略和存储仓库组合成一条可执行关系；
- **同步/备份**由 Agent 执行存储准备、备份或状态推进，平台接收事件并建立或更新恢复点；
- **恢复点**由源集群、保护配置、备份任务和 Velero 备份名共同确定，可查看状态、保留信息和内容清单；
- **Restore** 是恢复任务的能力与记录类型；已核验的恢复点操作入口是 **Drill** 和 **Takeover**，没有独立的 Restore 创建按钮。
- **Drill** 在隔离目标中验证恢复链路；**Takeover** 是经校验和变更审批的容灾切换。

恢复点处于创建中、来源不匹配、保护配置已删除或仓库不可访问时，不应启动恢复。任务成功后仍需检查目标工作负载、PVC、Service、应用健康和数据；删除平台中的恢复点记录，也不会立即擦除对象存储中的全部数据。

## 配置边界与安全责任

用户、组织、策略、任务、恢复点等控制台元数据保存在 PostgreSQL，秘密字段由 `HCDR_SECRET_KEY` 保护。

因此一份完整的平台备份必须同时保留：**数据库、`HCDR_SECRET_KEY`、TLS 文件、`.env`、版本清单和对象存储访问配置**。只备份数据库而没有密钥，可能无法解密存储凭据；只保留对象存储而没有控制台元数据，也无法恢复完整的管理面。

登录验证方式支持图片验证码和 Cloudflare Turnstile：图片验证码为四位数字/字母且字母不区分大小写；Turnstile 需要有效 key、浏览器可访问 Cloudflare 控件、服务端能出站校验。实际模式以安装目录 `.env` 为准。
