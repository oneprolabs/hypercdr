# Community SaaS：单组织账号模型

社区版支持用户自行注册并创建组织，或通过邀请加入组织。一个账号只能
属于一个组织，没有组织切换入口。界面使用“组织”，数据库继续使用
`tenant_id` 表示资源隔离范围。

## 身份与组织

- `users.username` 是固定登录账号；`users.email` 是可空、全局唯一的已验证绑定邮箱，验证时间为 `email_verified_at`。登录账号和其他用户的绑定邮箱不能交叉重复。`users.tenant_id` 非空，指向
  `resource_scopes`；不建立多组织成员关系表。
- 邮箱注册必须通过有效的验证链接；创建组织、创建管理员账号、消费
  验证令牌在一个 PostgreSQL 事务中完成。注册完成后创建登录会话。
- 邀请绑定邮箱、组织和角色，收件人通过邀请链接创建账号。已有账号
  不能通过邀请加入第二个组织。
- 组织管理员可邀请成员、修改组织信息、调整成员角色或禁用成员。
  普通成员可查看本组织信息。并发修改时也不能移除最后一位有效管理员。
  修改成员权限或状态后会撤销该成员现有会话。
- Google 登录验证签名、发行者、受众、有效期、已验证邮箱、nonce、
  PKCE 和浏览器状态。已有密码账号不会仅凭相同邮箱自动绑定 Google，
  应在 Sign-in & Security 中显式绑定。

## 资源边界

HTTP 会话确定组织范围，不能由客户端传入组织编号改变归属。集群、
存储、策略、保护计划、恢复点、任务等沿用核心的组织范围校验。
后台任务和 Agent 请求保留其原有资源所属组织，不以最后登录用户决定。
组织管理员不等于平台管理员；普通组织账号的 Dashboard 使用组织视角。

SaaS 接口位于 `/api/v1/saas/`。仅明确列出的 `/auth/` 公共接口允许匿名
访问；组织、成员、邀请和 Google 绑定接口仍需登录。变更请求检查来源，
注册接口提供速率限制；验证令牌以哈希保存并限制有效期和重复使用。

## 运行配置与两版边界

默认 `HCDR_DEPLOYMENT_MODE=saas`、`HCDR_SAAS_SIGNUP_ENABLED=true`。
邮箱注册及邀请使用平台配置的 SMTP；未配置时界面明确提示并禁用发送。
Google 按钮仅在 Client ID 和 Secret 均已配置时显示。
具体配置和回调地址见 [部署配置](../deployment/configuration.zh.md)。

公共注册页面及 Google 身份验证由两版共用；企业版保留自身的账号存储、
授权和许可流程。本次不引入历史数据迁移或旧版本兼容机制。

## 验证

`scripts/test-backend.sh ./pkg/saas ./internal/httpserver` 使用真实
PostgreSQL 验证注册、令牌重放、邀请、最后管理员保护和资源隔离。
Google 测试使用签名 JWT 与本地 OAuth/JWKS 服务；真实 Google 授权需
配置有效凭据及符合 Google 要求的回调域名后另行联调。

## 绑定邮箱

个人信息中的 Bound email 对邮箱形式登录账号只读（绑定邮箱与登录账号一致），API拒绝修改及旧验证链接；非邮箱登录账号支持绑定和修改。内置 `admin` 初始邮箱为空；邮件注册与 Google 注册使用已验证邮箱初始化绑定。绑定请求验证当前密码，并发送30分钟有效、单次使用的确认链接；确认前保留原绑定。确认后撤销该账号旧的密码重置令牌，保持固定登录账号、Google provider subject 和组织归属不变。密码恢复只匹配当前已验证绑定邮箱，不通过登录账号或其他恢复表推断地址。

数据模型由 `000044_user_bound_email.sql` 定义；待验证地址存储于 `user_email_verifications`，旧的 `admin_recovery_email` 已移除。对开发阶段已有数据库，应备份后迁移或重新部署；不能让旧镜像直接使用新结构。
